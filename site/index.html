How to read the columns

Every row is an Administrative Template policy from the Windows 11 24H2 policy definitions, plus the templates shipped with the two Microsoft baselines. The three percentage columns are the probability the model assigned to a yes answer; they are independent judgements, not a ranking.

  • Privacy: configuring the policy (Enabled or Disabled, with data-minimising options) would reduce collection, transmission or exposure of user and device data compared with leaving it Not Configured.
  • Security: configuring the policy would make the device harder to attack, compromise or misuse.
  • UX loss: configuring the policy in its most restrictive direction would directly degrade the experience of ordinary users (lost features, blocked actions, extra prompts, slower performance). Less telemetry, fewer ads or tips, and less personalisation do not count.
  • Privacy: set to / Security: set to: the state the model considers most privacy-protective or most secure. Shown as “—” when the model chose neither or the matching probability is below 50%; the underlying choice is in the row details.
  • RTLFB / Security Baseline: what Microsoft's Restricted Traffic Limited Functionality Baseline and Windows 11 24H2 Security Baseline set the policy to, decoded from the baseline registry.pol files. Only Administrative Template settings are shown.

Bands: below 35% 35 to 65% above 65%. Click a column header to sort; use the second header row to filter. Filters and sorting are kept in the page address so a view can be bookmarked.
